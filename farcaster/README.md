# SwipePad Farcaster Contracts

This directory contains smart contracts for the SwipePad Farcaster miniApp.

## Contracts

- **DonationHandler**: Handles direct donations from users to project wallets
- **BoostHandler**: Manages boost payments with a percentage fee going to SwipePad
- **MultiSigWallet**: Secure multi-signature wallet for SwipePad treasury funds

## Deployment

See `scripts/` directory for deployment scripts.
